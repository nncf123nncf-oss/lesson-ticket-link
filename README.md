# 回数券の残りリンク（lesson-ticket-link）

10回券・5回券などの回数券を、生徒ごとに「使った日」で記録すると、「ゆいさん 残り4回（10回券）」のように残りの回数と期限までの日数を出す1ページの道具です。記録はリンクにして生徒に送れ、生徒は登録なしで見られます。

- 先生の一覧（生徒30人まで）は、お使いの端末のブラウザ（localStorage）にだけ保存します。ブラウザのデータを消すと一覧も消えます。生徒に送ったリンクから一覧に取り込み直せます
- 生徒に送るリンクの中身はURLの `#` 以降に入ります。**リンクは作った時点の写しです。** あとで記録しても、前に送ったリンクの表示は変わりません
- サーバー・アカウントは使いません。閲覧数の計測に Cloudflare Web Analytics を使っています
- **値段・支払いは扱いません。** リンク・メールアドレス・7桁以上の数字・請求や振込に見える言葉・金額は入れられないようにしています（すべての言い方は防げません）
- まだ来ていない日は記録できません。有効期限より後に使った日には「期限後」の印が付きます（止めません）
